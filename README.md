# Digital Electronics Lab — ELP201

Verilog implementations, testbenches, waveforms, and reports from IIT Delhi's **ELP201: Digital Electronics Lab**.

## What is in this repository

The assignments implement and simulate synchronous digital-logic exercises. Source files are accompanied by Verilog testbenches, generated VCD waveform files, assignment briefs, and lab reports.

## Repository layout

- `Assignment 1/` to `Assignment 3/` contain the assignment documents and reports.
- Each assignment's `Code/` directory contains Verilog modules and testbenches; where available, VCD files capture simulation output.

## Notes

This is an academic archive. Run the Verilog files with a compatible simulator such as Icarus Verilog to reproduce the included testbench flows.
